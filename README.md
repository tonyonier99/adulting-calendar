# 台灣初級大人行事曆

供 [初級大人手冊](https://github.com/tonyonier99/AdultingGuide) iOS App 訂閱用的公開行事曆。

## 內容

每年 17 件對台灣大人實用的提醒，包含：

- **截止日**：報稅、機車稅、燃料費
- **節慶準備**：過年、清明、母親節、端午、七夕、中秋、聖誕、跨年等的「該準備了」提醒（不是節日當天）

不重複系統內建的台灣節日，只放系統不會給你的。

## 訂閱

iOS / macOS：
```
webcal://tonyonier99.github.io/adulting-calendar/calendar.ics
```

或在 App 內點「訂閱到我的 iOS 行事曆」。

Google Calendar：
- 設定 → 新增其他日曆 → 從網址訂閱
- 貼上：`https://tonyonier99.github.io/adulting-calendar/calendar.ics`

## 更新

每隔約 12 小時系統會自動拉新版本。

事件範圍：2026-2030（持續新增）。
